# 02 — გაქირავება

## 1. ძირითადი იდეა

ყიდვისას ვყიდით **ნივთს**. გაქირავებისას ვაქირავებთ **კონკრეტულ ფიზიკურ ეგზემპლარს** (`InventoryUnit`):
მას აქვს საკუთარი კოდი (QR), მდგომარეობა, ფოტოების ისტორია და კალენდარი.

```
Product „LEGO სახანძრო სადგური“ (ქირა ჩართულია)  ─┬─ Unit ZT-R-0101  (very_good, 12 გაქირავება)
                                                    └─ Unit ZT-R-0102  (good, 25 გაქირავება)
```

- მომხმარებელი ირჩევს **სათამაშოს და თარიღებს**, სისტემა თავად ანიჭებს თავისუფალ ეგზემპლარს (უკეთესი მდგომარეობა და ნაკლები გამოყენება — პრიორიტეტით).
- **წესი:** ფიზიკური ეგზემპლარი ან გასაყიდია, ან გასაქირავებელი, ორივე ერთად არა. ასე არ შეიქმნება სიტუაცია, როცა ნივთი ერთდროულად გაიყიდა და დაიჯავშნა. თუ მეპატრონე ქირის ეგზემპლარს გაყიდვაში გადაიტანს, სისტემა შეამოწმებს, რომ წინ ჯავშანი არ აქვს.
- **გეოგრაფია:** **[რეკომენდაცია]** ქირა — მხოლოდ ბათუმში (გატანა მაღაზიიდან ან ბათუმის კურიერით). მიწოდების მეთოდს აქვს ველი `allowsRental`, ამიტომ მოგვიანებით რეგიონების ჩართვა კოდის ცვლილებას არ მოითხოვს.

## 2. ფასი

### 2.1 ქირა — დღიური
`ქირა = დღიური_ფასი × დღეები × (1 − ხანგრძლივობის_ფასდაკლება)`

| პარამეტრი | სად ყენდება | ნაგულისხმევი **[დაშვება]** |
|-----------|-------------|-----------|
| დღიური ფასი | პროდუქტზე | ადმინი წერს (მინიშნება: გასაყიდი ღირებულების ~5–8%) |
| მინ. / მაქს. დღეები | პროდუქტზე (ან გლობალურად) | 1 / 30 |
| ხანგრძლივობის ფასდაკლება | გლობალურად (არჩევითი) | 7+ დღე −15%, 14+ დღე −25% |
| დღის განმარტება | გლობალურად | კალენდარული დღე: აღების დღე ითვლება, დაბრუნება — ბოლო დღეს მაღაზიის დახურვამდე |

### 2.2 დეპოზიტი — ჩამოჭრა და დაბრუნება
- გადახდისას ერთად ჩამოიჭრება **ქირა + დეპოზიტი** (ერთი ტრანზაქცია).
- დაბრუნებისა და შემოწმების შემდეგ დეპოზიტი (ან დაქვითვების შემდეგ დარჩენილი ნაწილი) ბრუნდება **ნაწილობრივი თანხის დაბრუნებით** (partial refund) იმავე ტრანზაქციაზე — ავტომატურად, ბანკის API-ით (BOG და TBC ორივე უჭერს მხარს).
- მყიდველს წინასწარ ვეუბნებით: „ბარათზე თანხის დაბრუნებას ბანკის მიხედვით რამდენიმე სამუშაო დღე სჭირდება“.
- ბათუმში გატანისას შესაძლებელია დეპოზიტი **ნაღდით** მაღაზიაში (ადმინში აღინიშნება, დაბრუნებაც ნაღდით).

### 2.3 დეპოზიტის ზომა — ყველაზე ნაკლები რისკი
**დეპოზიტი = ნივთის სრული ღირებულება** (ნაგულისხმევად = მისი გასაყიდი ფასი/შეფასება). ამ შემთხვევაში დაკარგვაც კი
სრულად დაფარულია და მაღაზია ზარალს არ ნახულობს. მეორადი სათამაშოები შედარებით იაფია, ამიტომ ასეთი დეპოზიტი მყიდველს არ აფრთხობს.
ადმინს შეუძლია თითოეულ პროდუქტზე შეცვალოს.

### 2.4 დაქვითვები (სამივე მექანიზმი, დეპოზიტიდან)

| შემთხვევა | წესი **[დაშვება]** |
|-----------|----------------|
| **დაგვიანება** | თითო დღეზე დღიური ფასი × 1.5; 7 დღეზე მეტი დაგვიანება → მენეჯერთან ზარი, შემდეგ „დაკარგულად“ ითვლება |
| **დაზიანება** | ადმინი ირჩევს შემოწმებისას: ნორმალური ცვეთა 0% · საშუალო 25% · მძიმე 50% · გამოუსადეგარი 100% (დეპოზიტიდან) |
| **დაკარგვა** | დეპოზიტი სრულად რჩება (= ნივთის ღირებულება) |
| **ძლიერ დაბინძურებული** | ფიქსირებული საწმენდი საფასური (მაგ. 5 ₾) |

ყოველ დაქვითვას სჭირდება **ფოტო** (გაცემისას და დაბრუნებისას გადაღებული) — დავის შემთხვევაში ეს მტკიცებულებაა.
ჯამური დაქვითვა არასდროს აჭარბებს დეპოზიტს; მყიდველი იღებს SMS/ელფოსტას დეტალებით და ფოტოებით.

### 2.5 ფასდაკლებები
თამაშით მოგებული ფასდაკლება ქირაზე **არ ვრცელდება** (გადაწყვეტილება #15). კლასიკური კუპონი — ადმინის არჩევანით.

## 3. ხელმისაწვდომობა

ეგზემპლარი დაკავებულია ინტერვალში `[აღების დღე, დაბრუნების დღე + 1 დღე ბუფერი)` — ბუფერი შემოწმებისა და გაწმენდისთვის.

```
                ქირა 5 დღე                    ბუფერი 1 დღე
  ──────[■■■■■■■■■■■■■■■■■■■■■■■]──────[▒▒▒▒]────────▶
       10 ნოე                     14 ნოე   15 ნოე   ← 16-დან ხელახლა თავისუფალია
```

- **კალენდარი პროდუქტის გვერდზე:** დღე თავისუფალია, თუ ერთი ეგზემპლარი მაინც თავისუფალია მთელი არჩეული პერიოდისთვის.
- **ორმაგი ჯავშნის აკრძალვა ბაზის დონეზე:** PostgreSQL `EXCLUDE USING gist (unit_id WITH =, blocked_period WITH &&)` აქტიურ სტატუსებზე (ხელით დაწერილი SQL მიგრაციაში).
- **დროებითი ჯავშანი:** კალათაში დამატებისას `held` 15 წუთით; გადახდის გარეშე — ავტომატური გაუქმება.

```
  held ──გადახდა (ქირა+დეპოზიტი)──▶ confirmed ──მომზადება──▶ ready ──┬─ გატანა ──────────┐
   │ (15 წთ)                            │                             └─ ბათუმის კურიერი ─┤
   ▼                                    ▼                                                   ▼
 expired                         cancelled (სრული თანხის დაბრუნება)                     active
                                                                                           │
                         ┌──── ვადა გავიდა, არ დაბრუნებულა ────┐       ┌── გამოსყიდვა ──┤
                         ▼                                      │       ▼                 │
                      overdue ──დაბრუნდა──┐        return_due (შეხსენება −1 დღე)   bought_out
                         │                ▼                     │                 (§6)

```

## 5. ფიზიკური პროცესი მაღაზიაში

1. **გაცემა:** ადმინი ტელეფონით სკანირებს ეგზემპლარის QR-ს → 2–4 ფოტო → ჩეკლისტი (ნაწილები, ელემენტები) → „გაცემულია“. სურვილისამებრ: მყიდველის პირადობის ნახვა (ნომერი ადმინში არ ინახება, მხოლოდ „შემოწმებულია“).
2. **დაბრუნება:** სკანირება → ფოტოები → ჩეკლისტი → დაქვითვები → სისტემა თავად აბრუნებს დეპოზიტს (ან დარჩენილ ნაწილს).
3. **გაწმენდა:** `cleaning` → თანამშრომელი ნიშნავს „მზადაა“ → `available`.

## 6. გამოსყიდვა

მომხმარებელს ნაქირავები მოეწონა → ანგარიშში ღილაკი „იყიდე“ (მაღაზიაშიც შესაძლებელია).
- **ფასი** = გასაყიდი ფასი − გადახდილი ქირის **50%** (გლობალური პარამეტრი) — მინიმუმი: გასაყიდი ფასის 50%.
- **დეპოზიტი ჩაითვლება ფასში:** თუ დეპოზიტი > გამოსყიდვის ფასი → სხვაობა ბრუნდება; თუ ნაკლებია → იხდის სხვაობას.
- ეგზემპლარი → `retired` (ქირიდან გადის), იქმნება შეკვეთა `kind: sale`.

## 7. UX — მომხმარებლის მხარე

- პროდუქტის გვერდზე **„იყიდე / იქირავე“** გადამრთველი (ქირის ვარიანტი — მხოლოდ თუ ქირა ჩართულია).
- „იქირავე“ → კალენდარი (აღების დღე → დაბრუნების დღე) ან სწრაფი არჩევანი „3 · 7 · 14 დღე“ → ჩანს: დღიური ფასი × დღეები, ხანგრძლივობის ფასდაკლება, **დეპოზიტი ცალკე ხაზად**, დაბრუნების დღე.
- ტექსტი: „დეპოზიტი გადახდისას ჩამოიჭრება და სათამაშოს დაბრუნებისა და შემოწმების შემდეგ ავტომატურად დაგიბრუნდება.“
- კალათაში ქირა — „ბილეთის“ სტილის ბარათი თარიღებით.
- ანგარიშში „ჩემი ქირავნობები“: დროის ზოლი, დარჩენილი დღეები, „გაგრძელება“ (თუ შემდეგი ჯავშანი არ ეჯახება), „იყიდე“.
- გვერდი „როგორ მუშაობს ქირა“ — 4 ნაბიჯი ილუსტრაციებით, ჰიგიენის სტანდარტი, დაქვითვების მკაფიო ცხრილი, FAQ.
