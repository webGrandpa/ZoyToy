# 05 — დიზაინ სისტემა და UX

> ვიზუალური კონცეფცია (ცოცხალი ფერები, ღილაკები, ბარათები, მინი-თამაშის დემო):
> [design/concept/index.html](../design/concept/index.html). ეს დოკუმენტი აღწერს წესებს, კონცეფცია — როგორ გამოიყურება.

## 1. ბრენდის მიმართულება: „სათამაშო ოთახი“ (Playroom Pop)

**იდეა:** საიტი არის **ხელშესახები სათამაშო ყუთი**, რომელშიც სათამაშოები **მეორე სიცოცხლეს** იწყებენ.
ყველაფერი ოდნავ „ფიზიკურია“: ღილაკები იჭყლიტება როგორც პლასტმასის ღილაკი, ბარათები ამოდის როგორც სტიკერი,
ფასი ტრიალდება როგორც მექანიკური მთვლელი. ვიზუალი მხიარულია, მაგრამ **სუფთა და ორგანიზებული** — მეორადი
ნივთის ყიდვისას ზრდასრულს უნდა ენდოს.

- **სავაჭრო ფენა** (ნივთის ინფორმაცია, მდგომარეობა, კალათა, checkout, ანგარიში) — მშვიდი, სწრაფი, ნათელი.

### არსებული ლოგოს შეფასება
Instagram-ის ლოგო (მრგვალი ბეჯი, ჟირაფი ბუშტებით და თავსატეხით, „ზოი თოი / ZOY TOY“) კარგი საწყისია — ჟირაფი
დასამახსოვრებელია და მეგობრული. საიტისთვის ვაკეთებთ **განახლებულ ვერსიას**:
- ჟირაფს ვხატავთ **თავიდან, ორიგინალურად** (თუ არსებული ნახატი clipart-ია ან AI-ით შექმნილი, მასზე ბრენდის საკუთრება სუსტია, ხოლო ზომებზე და ანიმაციაში ცუდად მუშაობს).
- ბეჯის ფორმა რჩება აპის იკონად/სტიკერად, ხოლო საიტის ჰედერში — ჰორიზონტალური ვერსია (ჟირაფის თავი + წარწერა).
- სოც. ქსელებში შემხვედრი მეორე ლოგო („ZOY TOYS“ ფერადი ასოებით) **აღარ გამოიყენება** — ერთი ბრენდი, ერთი ნიშანი.

## 2. მასკოტი — „ზოი“ ჟირაფი

მეპატრონის ერთადერთი არსებული იდეა — Instagram-ის ჟირაფი — **ხდება მასკოტი**. ის საიტზე მეგზურია: ხსნის თამაშის წესებს,
ხვდება ცარიელ კალათაში, ზეიმობს შეკვეთას, „ეძებს“ 404-ზე.

**კონცეფცია: ჟირაფი, რომელიც სათამაშო ყუთში ცხოვრობს.** ზოი ყუთიდან ამოყოფს თავს (სათამაშოების ყუთი = მაღაზია, სადაც
სათამაშოები მეორე სიცოცხლეს იწყებენ). ჟირაფის **გრძელი კისერი** ანიმაციისთვის იდეალურია:
| მომენტი | ანიმაცია |
|---------|----------|
| ჩატვირთვა | კისერი ნელა იზრდება — როგორც progress bar |
| ძებნა / 404 | თავი ყუთიდან ამოდის და აქეთ-იქით იყურება, თითქოს თაროებს ათვალიერებს |
| კალათაში დამატება | ყუთში ჩაყვინთავს და სათამაშოთი ამოხტება |
| მოგება / შეკვეთა | ყუთიდან ამოხტება, ბუშტები მაღლა მიფრინავს, კონფეტი |
| ცარიელი კალათა | ყუთში მარტო ზის, მოწყენილი, ერთი ბუშტით |

**ბრენდის ელემენტები ლოგოდან:** ყვითელი/ნარინჯისფერი ჟირაფი ლაქებით → `sun` + `tangerine` ტოკენები;
**ბუშტები** (5 ფერის) → ზუსტად ჩვენი აქცენტური ფერები და კატეგორიების ფერები; **თავსატეხის ნაწილები** → დეკორატიული მოტივი და იკონები.
იისფერი (`grape`) მოქმედების ფერად რჩება — ის ყვითელი ჟირაფის **დამატებითი** ფერია და ყველაზე მკაფიოდ ეწინააღმდეგება მას.

მასკოტის მოთხოვნები: მარტივი სილუეტი (32px-ზეც იცნობა), 4–5 ფერი, მუშაობს 2D-შიც და 3D-შიც.
ემოციების ნაკრები: მისალმება, სიხარული, ზეიმი, ფიქრი, დაბნეულობა, ძილი, მოლოდინი, „აჰა!“.
**ტექნიკა:** 2D — Figma; ინტერაქტიული — **Rive** (state machine: idle → hover → tap → celebrate → sad; თვალები მიჰყვება კურსორს);
3D — Blender (მთავარი გვერდის სცენისთვის, ფაზა 1-ის ბოლოს).

## 4. ტიპოგრაფია (ქართული პირველ რიგში!)

ქართული შრიფტის არჩევანი შეზღუდულია — ეს **ადრეული გადაწყვეტილებაა**, რადგან ყველაფერზე მოქმედებს.

| როლი | შრიფტი | შენიშვნა |
|------|--------|----------|

- ბადე: მობ. 2 სვეტი, ტაბ. 3, დესკ. 4. ბარათზე: ფოტო (1:1, `contain`, კატეგორიის ფერის ღია ფონზე), მდგომარეობის ბეჯი, სახელი (მაქს. 2 ხაზი), ფასი + „ახლის ~X ₾“, ქირა „4 ₾/დღე“, სწრაფი „+“ ღილაკი. გაყიდული ნივთი სიიდან ქრება.
- ცარიელი შედეგი — მასკოტი ყუთში ეძებს + შეთავაზებები.

### პროდუქტის გვერდი (PDP)
- **ზემოთ (ერთ ეკრანზე მობილურზეც):** გალერეა → სახელი, ბრენდი/ფრენჩაიზი → **მდგომარეობის ბეჯი** → ფასი + დაზოგვა → **ყიდვა/ქირა გადამრთველი** → (ქირა: დღეები + კალენდარი + დეპოზიტი) → მთავარი ღილაკი → „ერთადერთი ცალი · ბათუმის მაღაზიაში“ → მიწოდების ვარიანტები ფასით.
- მობ.: მთავარი ღილაკი **მიმაგრებულია ქვემოთ** (sticky), ფასით.
- **🎮 თამაშის ბლოკი** (თუ კამპანია აქტიურია): „ითამაშე და მოიგე −50%-მდე“ + დარჩენილი ცდები (მხოლოდ ყიდვის რეჟიმში; ქირაზე ბლოკი ჩანს ნაცრისფრად: „ფასდაკლება ქირაზე არ ვრცელდება“).
- ქვემოთ: **მდგომარეობის პანელი** (ხარვეზები ფოტოებით, რა აკლია, შემოწმებულია/გაწმენდილია), აღწერა, მახასიათებლები, ასაკი და **უსაფრთხოება** (მკაფიოდ — მშობლებისთვის მნიშვნელოვანია), „ყუთში რა არის“, მიწოდება/დაბრუნება, ქირის წესები, შეფასებები, მსგავსი სათამაშოები, „ამ ფრენჩაიზიდან“.

### კალათა და checkout
- კალათა — გვერდითა drawer (დესკ.) / სრული გვერდი (მობ.). ყიდვის და ქირის ელემენტები ერთად, ქირა — „ბილეთის“ სტილის ბარათით (თარიღებით).
- თამაშით მოგებული ჯილდოები ავტომატურად ჩანს და იყენება (ან არჩევა, თუ რამდენიმეა).
- Checkout — **ერთი გვერდი, 3 ბლოკი**: კონტაქტი (ტელეფონი; ფასდაკლების ან ქირის შემთხვევაში — SMS დადასტურება იქვე) → მიწოდება (DeliveryPicker: ქალაქის მიხედვით ჩანს მხოლოდ შესაძლო მეთოდები) → გადახდა (ბარათი BOG/TBC; გატანისას — ადგილზე). სტუმრად ყიდვა ნებადართულია.
- ნათლად ჩანს: ჯამი, მიწოდება (ან „მიწოდებას გადაიხდი მიღებისას“), ფასდაკლება, **დეპოზიტი ცალკე ხაზად** („ჩამოიჭრება და დაბრუნების შემდეგ დაგიბრუნდება“).
- წარმატება — ყუთის გახსნის ზეიმი + შეკვეთის დეტალები + „რა მოხდება შემდეგ“.

### `/play` — სათამაშო მოედანი
ყველა აქტიური კამპანია ბარათებად (თამაშის პრევიუ-ანიმაცია, პროდუქტი, მაქს. ფასდაკლება, ვადა, დარჩენილი ცდები), „ჩემი ჯილდოები“.

### ანგარიში
შეკვეთები (დროის ზოლით), ქირავნობები (დარჩენილი დღეები, „გაგრძელება“), ჯილდოები და კუპონები, სურვილების სია, მისამართები, პარამეტრები (ენა, ხმა, შეტყობინებები, მონაცემების წაშლა).

### სისტემური გვერდები
404 (მასკოტი დაიკარგა სათამაშოებში), 500, ოფლაინი (PWA), ტექნიკური სამუშაოები — ყველა საკუთარი ილუსტრაციით.

### 11.2 მთავარი გვერდი
- **3D Hero — „სათამაშოს მეორე სიცოცხლე“:** scroll-ით სათამაშო ყუთი იხსნება, ჟირაფი ამოიხედება, სათამაშოები ამოფრინდება და თითოეული შემდეგ სექციაში „დაჯდება“ (Three.js; სუსტ მოწყობილობაზე — წინასწარ დარენდერებული ვიდეო ან სურათი).
- **„ახალი შემოსვლები“ სთორიებად** — მრგვალი ჩარჩოები ზემოთ, როგორც Instagram-ზე (აუდიტორია Instagram-იდან მოდის და ეს ფორმატი ნაცნობია): შეხებით სრულეკრანიანი სლაიდები ფოტოებით, ფასით და ღილაკით „ვნახო“. ახალი ნივთის სთორის ჩარჩო ფერადად ციმციმებს.
- **ილუსტრირებული ვიტრინა** — ბათუმის მაღაზიის სახალისო ილუსტრაცია. თაროებზე დაჭერით შესაბამის კატეგორიაში გადადიხარ, hover/შეხებისას თარო ანათებს და სათამაშო ირხევა.
- **„სათამაშოს მოგზაურობა“** — ანიმირებული რუკა: თვითმფრინავი აშშ-იდან და ევროპიდან ბათუმამდე → შემოწმება → გაწმენდა → შენს სახლამდე. მეორადის მესიჯი ისტორიის სახით.
- **დაზოგვის მთვლელი** — „ჩვენმა მყიდველებმა ახლის ფასთან შედარებით უკვე დაზოგეს X ₾“ (ციფრი ადმინიდან განახლდება, მექანიკური მთვლელივით ტრიალებს).
- **ანიმირებული ქართული სათაურები** — ასოები სათითაოდ, ზამბარით „ჩამოხტება“ (ტექსტი ხელმისაწვდომი რჩება).

### 11.3 კატალოგი და ბარათები
- **გვერდებს შორის „ფრენა“** (View Transitions API): ბარათის ფოტო შეუფერხებლად იზრდება პროდუქტის გვერდის გალერეად, უკან დაბრუნებისას ისევ ბარათში ჩაჯდება.
- **ბარათის გადაბრუნება** — „ⓘ“ ღილაკით ბარათი 3D-ში ბრუნდება და უკანა მხარეს მდგომარეობის მოკლე აღწერა ჩანს (ხარვეზები, სისრულე, შემოწმებულია/გაწმენდილია).
- **კატეგორიის სამყაროები** — ყოველ კატეგორიას თავისი ფერი, ილუსტრირებული ჰედერი პარალაქსით და პატარა ანიმირებული დეტალი (მანქანები — გზაზე მიმავალი მანქანა; რბილი სათამაშოები — ფუმფულა ღრუბლები; კონსტრუქტორები — თავისით აწყობადი კოშკი).
- **სათამაშოს სილუეტის ჩონჩხი** — ჩატვირთვისას ცარიელი ბარათების ნაცვლად სათამაშოების ფერადი სილუეტები ციმციმებს.
- **ასაკის სლაიდერი** — ჟირაფი სლაიდერის გასწვრივ იზრდება: პაწია ჟირაფი (0–2) → მოზარდი → დიდი (12+).
- **მობილურზე** — ზემოდან ჩამოწევისას გვერდი განახლდება და ჟირაფის კისერი იჭიმება.

### 11.4 პროდუქტის გვერდი
- **ხარვეზების ლუპა** — ფოტოზე პატარა მოციმციმე წერტილები (ადმინი სვამს ფოტოზე დაჭერით). წერტილზე შეხებით ის ადგილი ლუპით დიდდება და მოკლე აღწერა ჩანს („მცირე ნაკაწრი“). გამჭვირვალობა ნდობას აჩენს.
- **360° ტრიალი** — ტოპ ნივთებზე თითის გასმით ბრუნავს (24 კადრი).
- **AR „ნახე შენს მაგიდაზე“** — ნივთებზე, რომლებსაც 3D მოდელი აქვთ (`<model-viewer>`, iOS/Android-ის ჩაშენებული AR, უფასო).
- **დაზოგვის ქილა** — „ახლის ფასი ~120 ₾“ ქილად ჩანს, რომელიც მონეტებით ივსება და ციფრი „დაზოგე 75 ₾“ ტრიალებს.
- **მდგომარეობის შკალა** — 6 დონის ზოლი, მიმდინარე დონეზე ჟირაფის თათი.
- **„გააზიარე სთორიში“** — ბრაუზერი ამზადებს ლამაზ სურათს (ნივთის ფოტო, ბრენდის ჩარჩო, ფასი, ჟირაფი) და ტელეფონზე Instagram-ში გასაზიარებლად იხსნება (Web Share). უფასო მარკეტინგია.

### 11.5 კალათა და მოთხოვნა
- **სურვილების ყუთი** — ❤️-ზე დაჭერისას ნივთის ფოტო ვარდება ყუთში (მსუბუქი ფიზიკა). ყუთი ჰედერშია და ნივთების რაოდენობასთან ერთად ივსება. ბმულით გაზიარება შესაძლებელია („ბებოს გაუგზავნე, რა მინდა საჩუქრად“), სერვერის გარეშე, ბმულში ჩაწერილი ნივთების ნომრებით.
- **„საჩუქრის რეჟიმი“** — შეკვეთისას „საჩუქარია?“ გადამრთველი: ბარათი სადღესასწაულო ქაღალდში „შეიფუთება“ და მისალოცის ველი ჩნდება (მეპატრონე ბარათს ხელით წერს).
- **შეფუთვის ზეიმი** — მოთხოვნის გაგზავნისას შერჩეული ნივთების ფოტოები ყუთში ჩაცვივა, ყუთი ლენტით იკვრება, ჟირაფი „ZOY“ ბეჭედს არტყამს, ბუშტები აფრინდება. ამის შემდეგ ჩნდება WhatsApp / Telegram / Instagram ღილაკები ([08 §3](08-lite-mvp.md#3-ხელით-სამუშაოს-ხელსაწყოები-მეპატრონისთვის-მაქსიმალურად-მარტივად)).
- **ფასის მთვლელი** ყველა ცვლილებაზე (ფასდაკლება, მიწოდება).

### 11.6 სტიკერების ალბომი (ბავშვებისთვის)
- 24 სტიკერი: ჟირაფი სხვადასხვა კოსტიუმში და პროფესიაში (მზარეული, კოსმონავტი, მეხანძრე, მუსიკოსი…) + იშვიათი „ოქროსფერი“ სტიკერები.
- სტიკერს იღებ საიტის დათვალიერებისას: ახალ კატეგორიაში შესვლა, თამაშის დასრულება, სთორიების ბოლომდე ნახვა, საიდუმლოს პოვნა.
- ალბომი შეხებით იშლება და გვერდები ფიზიკურად გადაიფურცლება. სრული გვერდი თამაშის ახალ სკინს ხსნის.
- ინახება ბრაუზერში და ფასდაკლებას **არ** იძლევა. ეს მხოლოდ გართობაა: ბრუნდებიან და ერთობიან. ფასდაკლება მხოლოდ თამაშებიდან მოდის.

### 11.7 თამაშები და სისტემური გვერდები
- 3 თამაში ([03](03-gamification.md)) + **ჩაცმის სკინები** სეზონის მიხედვით (საახალწლო Toy Drop-ში ფიფქები და სასაჩუქრე ყუთები).
- **404 = მინი-თამაში** — „ჟირაფმა ბუშტები გაუშვა, დაიჭირე!“ (ფასდაკლების გარეშე, უბრალოდ სახალისოა) + ღილაკი მთავარზე.
- **ოფლაინ გვერდი (PWA)** — ჟირაფი ყუთში იმალება ქოლგით, „ინტერნეტი წავიდა, მაგრამ შენი კალათა შენახულია“.
- **ჩატვირთვა** — ჟირაფის კისერი, როგორც პროგრესის ზოლი.

### 11.8 ხმა და შეგრძნება
- ხმების ნაკრები (pop, click, „ყუთის გახსნა“, მონეტები, ჟირაფის სასაცილო ბგერები) — ნაგულისხმევად გამორთულია, ჰედერიდან ირთვება.
- **ვიბრაცია** (Android): კალათაში დამატებისას, თამაშში დაჭერისას, მოგებისას — მოკლე, ნაზი.
- გვერდის ზედა ზოლის ფერი (`theme-color`) კატეგორიის ფერს იღებს.

### 11.9 შეზღუდვები (რომ ხიბლმა ხელი არ შეუშალოს)
- სავაჭრო გზაზე (ფასი, მდგომარეობა, კალათა, ფორმა) ხიბლის ფენა **არასდროს** ფარავს ინფორმაციას და არ აყოვნებს მოქმედებას.
- ყველა ანიმაცია გამოტოვებადია. reduced-motion → სტატიკური ვერსიები; სუსტ მოწყობილობაზე 3D, ვიდეო და ფიზიკა ავტომატურად ითიშება.
- ერთ ეკრანზე **ერთი** მთავარი „ვაუ“ მომენტი. დანარჩენი — წყნარი მიკრო-ინტერაქციებია.
