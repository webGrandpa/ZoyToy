# 06 — ასეტების სია

**აღნიშვნები**
- **პრიორიტეტი:** `P0` — MVP-მდე აუცილებელი · `P1` — გაშვებისთვის სასურველი · `P2` — გაშვების შემდეგ
- **წყარო:** `🎨 შექმნა` (ჩვენ ვქმნით: Blender / After Effects / Photoshop / Figma) · `🛒 მოპოვება` (ყიდვა, ლიცენზია, მომწოდებელი) · `💻 კოდი` (პროგრამულად იქმნება — ასეტი არ სჭირდება)
- **ინსტრუმენტი:** BL = Blender · AE = After Effects · PS = Photoshop · FG = Figma · RV = Rive (უფასო ვებ-რედაქტორი; ინტერაქტიული პერსონაჟისთვის — **ერთადერთი ინსტრუმენტი, რომელიც სიაში არ გაქვს**)

ყველა ასეტი ორიგინალი უნდა იყოს. ფრენჩაიზების პერსონაჟები/ლოგოები — მხოლოდ რეალურ პროდუქტის ფოტოებში (ოფიციალურ მასალებზე წვდომა არ გვაქვს; იხ. [00 §7.1](00-vision-and-scope.md#71-ფრენჩაიზები-და-სავაჭრო-ნიშნები)).

**საწყისი მასალა:** Instagram-ის ლოგო (ჟირაფი ბუშტებით და თავსატეხით, „ზოი თოი / ZOY TOY“) — ინსპირაციაა, ფაილად არ გამოვიყენებთ: ჟირაფი ვექტორში თავიდან იხატება (იხ. [05 §1](05-design-system.md#არსებული-ლოგოს-შეფასება)).

## ასეტების წყაროების საქაღალდე და წესები

```
design/
├─ concept/            ვიზუალური კონცეფცია (HTML)
├─ figma/              Figma-ს ექსპორტები, ბმულები (README-ში)
├─ source/             წყარო ფაილები (Git LFS-ით): *.blend, *.aep, *.psd, *.riv
│  ├─ brand/  mascot/  illustrations/  3d/  games/{toy-drop,memory,puzzle}/  sound/
└─ export/             მზა ფაილები, რომლებიც კოდში გადადის (ასევე LFS)
```

**სახელები:** `kebab-case`, ინგლისურად, ვერსიის გარეშე (ვერსიებს Git აკონტროლებს): `mascot-celebrate.lottie`, `cat-plush.webp`, `toy-drop-atlas.webp`.

**ექსპორტის წესები**
| ტიპი | წესი |
|------|------|
| რასტრი | sRGB, PNG-24 (გამჭვირვალე) ან JPG 90 → აპი თავად აკეთებს AVIF/WebP ზომებს; @2x |
| ვექტორი | SVG, ტექსტი — მრუდებად, ID-ების გარეშე, `viewBox` შენახული, SVGO-ით გასუფთავებული |
| Blender → GLB | Y-up, მოდიფიკატორები გამოყენებული, ტექსტურები 2-ის ხარისხი (512/1024/2048), baked AO/განათება; შემდეგ `gltf-transform` → meshopt + KTX2 |
| Lottie | 60fps (ან 30), ≤ 3 წმ, ≤ 120KB, shape layers |
| ხმა | 48kHz ჩაწერა → Opus 96kbps + MP3 128kbps; ნორმალიზება |
