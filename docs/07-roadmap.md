# 07 — ეტაპები (სრული ვერსია)

> **გადაწყვეტილება:** ვიწყებთ [საწყისი ვერსიით (08)](08-lite-mvp.md) (~13–15 კვირა, უფასო ინფრასტრუქტურა, ფასიანი სერვისები ხელით, სრული დიზაინი + ხიბლის ფენა).
> ქვემოთ აღწერილი ეტაპები მის შემდეგ, [08 §5](08-lite-mvp.md#6-როდის-ჩავრთოთ-ფასიანი-სერვისები)-ის სიგნალების მიხედვით, ნაწილ-ნაწილ ემატება.

მუშაობა მიდის **ორ პარალელურ ხაზად**: 🎨 დიზაინი/ასეტები და 💻 განვითარება. დიზაინი ყოველთვის ერთი ეტაპით წინ უნდა იყოს.
ვადები მიახლოებითია (ერთი დეველოპერი + AI დახმარება, ერთი დიზაინერი) და დაზუსტდება ეტაპი 0-ის შემდეგ.


## ეტაპი 0 — გადაწყვეტილებები და დიზაინის საფუძველი (🎨, 2–3 კვირა)
- [x] მეპატრონემ უპასუხა პირველ 18 კითხვას ([გადაწყვეტილებების ჟურნალი](00-vision-and-scope.md#8-გადაწყვეტილებების-ჟურნალი))
- [ ] ახალ ღია კითხვებზე პასუხი ([00 §9](00-vision-and-scope.md#9-ღია-კითხვები-ახალი)): სახელი, ქირის გეოგრაფია, რუსული ენა, ავტობუსით მიწოდების გადახდა, ნაღდი
- [ ] ჟირაფის განახლებული დიზაინი → ლოგო; display შრიფტის გადაწყვეტილება
- [ ] **პროდუქტის ფოტოგადაღების დაწყება** (სტანდარტი 10 ნივთზე → შემდეგ მასობრივად; ~1 000 ნივთს თვეები სჭირდება, ამიტომ განვითარების პარალელურად მიდის)

- [ ] მთავარი გვერდის, PLP-ის და PDP-ის **მობილური** დიზაინი → მეპატრონის დადასტურება
- [ ] ბანკებთან ხელშეკრულება და სატესტო გასაღებები — **BOG და TBC ორივე** (ამას დრო სჭირდება, ადრე დავიწყოთ)

- **მზადაა, როცა:** ბრენდი და 3 მთავარი გვერდი დადასტურებულია, ღია კითხვებზე პასუხები ჩაწერილია.

- [ ] Postgres, R2 — ლოკალურად Docker Compose-ით; production სერვერი (Caddy, backup)
- [ ] CI: lint, typecheck, ტესტები, preview დეპლოი
- [ ] დიზაინ ტოკენები → `tokens.css` + Tailwind preset; Storybook
- [ ] ბაზისური კომპონენტები (Button-ის „ჭყლეტით“, Input, Badge, Card, Modal, BottomSheet, Toast)
- [ ] i18n (ka/en, მზადყოფნა ru-სთვის) მარშრუტები, FiraGO
- [ ] ავთენტიფიკაცია (ტელეფონი + OTP, ელფოსტა), როლები
- **მზადაა, როცა:** ცარიელი საიტი ჰედერით/ფუტერით/ნავიგაციით გაშლილია staging-ზე, ადმინში შესვლა მუშაობს.

## ეტაპი 2 — კატალოგი და ადმინის CRUD (💻, 3 კვირა)

- [ ] ფოტოების პაიპლაინი: HEIC, EXIF/GPS წაშლა, 1:1 ჭრა ფიქსირებული თანაფარდობით, ბარათის პრევიუ, ვალიდაცია
- [ ] ადმინი: ნივთის სწრაფი დამატება ტელეფონიდან, სრული CRUD, ვერსიები, დრაფტები, პრევიუ, მასობრივი მოქმედებები, AuditLog
- [ ] **QR ეტიკეტების ბეჭდვა** + **„მაღაზიაში გაყიდვა“** ეკრანი (სკანირებით) + გაყიდული ნივთის ლოგიკა
- [ ] საწყისი კატალოგის იმპორტი (CSV/Excel + ფოტოები SKU-ით)
- [ ] მთავარი გვერდი (ბლოკებით, Live Preview), PLP ფილტრებით (მდგომარეობის ჩათვლით), ძებნა (pg_trgm), PDP (გალერეა, მდგომარეობის პანელი)
