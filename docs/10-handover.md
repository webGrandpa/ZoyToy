# 10. მეპატრონისთვის გადაცემა

როცა საიტი დამკვეთს გადაეცემა: შეკვეთები, ბოტი და კონტაქტები — მის ხელში; Vercel, GitHub და ბაზა — ისევ
დეველოპერთან (საიტის განახლება და ატვირთვა [09](09-deploy.md)-ით). ახალი ბოტი **არ არის საჭირო** — ბოტი ტელეფონის
ნომერზე არ არის მიბმული, `@zoy_toy_bot` რჩება.

## 1. დამკვეთის ანგარიში ადმინში

ადმინი → **თანამშრომლები** → ახალი → ელფოსტა, პაროლი, როლი:

| როლი | ვისთვის | რა შეუძლია |
|------|---------|------------|
| **მეპატრონე (ყველა უფლება)** | დამკვეთი | ყველაფერი, მათ შორის საიტის პარამეტრები და ბოტის ჩატის შეცვლა |
| **თანამშრომელი** | მისი გამყიდველები | ნივთები, შეკვეთები, მაღაზიაში გაყიდვა, ეტიკეტები; პარამეტრებს ვერ ცვლის |

> პაროლის აღდგენა ელფოსტით ჯერ არ მუშაობს (ელფოსტის სერვისი მიერთებული არ არის). დავიწყებულ პაროლს მეპატრონე ან
> დეველოპერი ცვლის ადმინიდან: თანამშრომლები → ანგარიში → ახალი პაროლი.

## 2. შეკვეთები დამკვეთის Telegram-ში

ბოტი შეკვეთებს **ერთ** ჩატში აგზავნის — ახლის დაკავშირებისას ძველში აღარ მოვა.

**ჯგუფი (რეკომენდებული):**
1. Telegram-ში ჯგუფი, მაგ. „Zoy Toy შეკვეთები“ — დამკვეთი + დეველოპერი (+ გამყიდველები).
2. ადმინი → საიტის პარამეტრები → Telegram → **„👥 ჯგუფთან დაკავშირება“** → აირჩიე ჯგუფი → ბოტი წერს „✅ ჯგუფი დაკავშირდა“.
3. პირველ დღეებში დეველოპერიც ხედავს, როგორ მიდის საქმე; მერე უბრალოდ გამოდის ჯგუფიდან.

**დამკვეთის პირადი ჩატი:** მისი ადმინიდან **„📱 პირად ჩატთან დაკავშირება“** → Start. ან დეველოპერი ამ ღილაკზე
მარჯვენა ღილაკით → „Copy link“ → უგზავნის WhatsApp-ით → დამკვეთი ხსნის და აჭერს Start-ს (ბმული 30 წუთი მოქმედებს).

ბოლოს: **„🧪 სატესტო შეტყობინება“** — უნდა მივიდეს მასთან. დილის შეჯამებაც იმავე ჩატში წავა.

## 3. ბოტის მფლობელობა (არასავალდებულო)

ბოტი ეკუთვნის იმ Telegram-ანგარიშს, რომელმაც შექმნა. დამკვეთზე გადასაცემად:
1. დამკვეთმა ერთხელ მაინც დააჭიროს ბოტში **Start**-ს (მე-2 ნაბიჯში ისედაც აკეთებს).
2. ძველი მფლობელი: **@BotFather** → `/mybots` → `@zoy_toy_bot` → **Transfer Ownership** → **Choose recipient** →
   დამკვეთის username → დადასტურება (შეიძლება ორსაფეხურიანი დაცვის პაროლი მოითხოვოს; ვებ-ვერსიაში ეს ღილაკი შეიძლება არ ჩანდეს — ტელეფონიდან).
3. ამის მერე სახელს, სურათს, აღწერას (`/setname`, `/setuserpic`, `/setdescription`) თვითონ ცვლის.
4. თუ გადაცემის მერე ბოტი გაჩუმდა ან დამკვეთმა `/revoke`-ით ახალი ტოკენი აიღო — ახალი ტოკენი Vercel-ში:
   `vercel env rm TELEGRAM_BOT_TOKEN production` → `vercel env add TELEGRAM_BOT_TOKEN --environment production --sensitive`
   → ხელახლა ატვირთვა ([09 §5](09-deploy.md#5-telegram-ბოტი)) → ადმინში კავშირის ბლოკი უნდა იყოს მწვანე.

## 4. საიტზე ნაჩვენები კონტაქტები

მყიდველის ყველა „მოგვწერე / დაგვირეკე“ ღილაკი აქედან იღებს მონაცემს. ადმინი → **საიტის პარამეტრები** → **კონტაქტი**:

| ველი | ფორმატი | სად ჩანს |
|------|---------|----------|
| ტელეფონი | `+995 5XX XX XX XX` | კონტაქტის გვერდი, ფუტერი |
| WhatsApp | `9955XXXXXXXX` (საერთაშორისო, ციფრებით) | ნივთის გვერდის „იკითხე“, კალათა, კონტაქტი |
| Telegram | username `@`-ის გარეშე (მისი პირადი — არა ბოტის) | „იკითხე“, კონტაქტი |
| Viber | `9955XXXXXXXX` | კონტაქტი |
| ელფოსტა | | კონტაქტი |
| სოციალური ქსელები | ბმული ან სახელი | ფუტერი, კონტაქტი |
| სამუშაო საათები | თითო ენაზე (ზემოთ „შინაარსის ენა“) | კონტაქტი |

ცარიელი ველი საიტზე არ ჩანს. ბოტის ბარათზე **💬 WhatsApp** და **📞 დარეკვა** მყიდველს იმ ტელეფონიდან უკავშირდება,
რომლიდანაც დააჭერენ — დამკვეთთან თავისით მისი ნომრიდან იმუშავებს.

## 5. შემოწმება გადაცემის მერე

- [ ] დამკვეთი შედის ადმინში თავისი ანგარიშით
- [ ] Telegram-ის ბლოკი მწვანეა, სატესტო შეტყობინება მივიდა მასთან
- [ ] საიტზე სატესტო შეკვეთა → ბარათი მის ჩატში → „❌ გაუქმება“ (ნივთი თაროზე ბრუნდება)
- [ ] კონტაქტის გვერდზე მისი ნომრები და ქსელებია; ნივთის გვერდზე „WhatsApp“ მის ნომერზე ხსნის ჩატს
- [ ] ფოტოების მომზადება — [§6](#6-ნივთის-ფოტოები)

## 6. ნივთის ფოტოები

საიტის ბარათებს ერთი სტილი აქვს: პასტელური ფონი, ნათელი წრე და პატარა გორაკი. რომ დამკვეთის ფოტოებიც ამ
სამყაროში ჩაჯდეს, **სათამაშოს ფოტოს ფონი უნდა მოაშოროს** — საიტი სათამაშოს თვითონ დასვამს ნახატ ფონზე.

**ფონის მოშორება (ერთ-ერთი):**
- iPhone: „ფოტოებში“ სათამაშოზე თითი დიდხანს → „გაზიარება“ → „სურათის შენახვა“ (ინახება ფონის გარეშე).
- Samsung: გალერეაში სათამაშოზე თითი დიდხანს → „სურათად შენახვა“.
- ნებისმიერ მოწყობილობაზე: remove.bg ან Photoroom (უფასოდ).

**ატვირთვა:** ნივთი → ფოტოები → ახალი ფოტო. ატვირთე **PNG** (JPG გამჭვირვალე ფონს ვერ ინახავს).
ბლოკში **„ფონი საიტზე“** მაშინვე ჩანს, როგორ გამოჩნდება:
- ✅ „ფონი მოშორებულია“ → აირჩიე **ფერი** (ან „A“ — ნივთის კატეგორიის ფერი) და **ნახატი**: „წრე და გორაკი“ (სათამაშო გორაკზე დგას),
  „ვარსკვლავები“ ან „სადა“.
- ℹ️ ყვითელი შეტყობინება → ფოტოს საკუთარი ფონი აქვს და ისე გამოჩნდება, როგორც არის (ასეც შეიძლება, მაგრამ საიტის სტილს ნაკლებად ერგება).

ცარიელ კიდეებს საიტი თვითონ მოაჭრის, ამიტომ სათამაშო ყოველთვის ბარათის ზომაზე ჩანს. ფონის შეცვლა შეიძლება
მოგვიანებითაც: ფოტოები → ფოტო → სხვა ფერი → შენახვა (საიტზე მაშინვე ჩანს). Telegram-ში შეკვეთის ფოტოც იმავე
ფერზე მოდის.

**რჩევები გადაღებისთვის:** კარგი დღის სინათლე, სათამაშო მთლიანად კადრში, სადა ფონი (თეთრი ფურცელი) — ასე
ფონის მოშორება უფრო სუფთად გამოდის. დეფექტის ახლო ფოტოებს ფონის მოშორება არ სჭირდება.
